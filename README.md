# 📉 Telecom Customer Churn Prediction

## 📌 Project Overview
This project predicts whether a telecom customer is likely to leave the service (churn) based on their usage, billing, and demographic data. Identifying at-risk customers helps businesses improve retention strategies.

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Environment:** Google Colab / Jupyter Notebook
* **Libraries:** Pandas, Scikit-Learn, Matplotlib, Seaborn

## 💡 Key Highlights & Concepts Covered
1. **Real-World Data:** Used the IBM Telco Customer Churn dataset (7,000+ records).
2. **Data Preprocessing:** Handled missing numeric values and encoded categorical text variables using `LabelEncoder`.
3. **Model Training:** Built a robust classification model using a **Random Forest Classifier**.
4. **Performance Metrics:** Evaluated the model achieving a solid Accuracy of **79.25%** and an ROC-AUC score of **0.81**.
5. **Business Insights:** Extracted Feature Importance to identify the top driving factors behind customer churn (e.g., Total Charges, Tenure, Contract Type).
